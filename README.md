# Model-Based Systems Engineering (RFLP): Active Pedestrian-Impact Mitigation System

Course project for *Concept Design of New Vehicles* (MSc Autonomous Vehicle Engineering, University of Naples Federico II, 2026). Individual project.

## Summary
Design and verification of an active pedestrian-protection system through a full **RFLP (Requirements → Functional → Logical → Physical)** workflow within the Pahl & Beitz design framework.

## What's inside
- **SysML model suite** in Visual Paradigm (`model/RLSS_final.vpp`): Use Case, Block Definition, Internal Block, Sequence and State Machine diagrams.
- **18-requirement hierarchy** in the Simulink Requirements Editor (`model/RLSS_Requirements.slreqx`), with traceability matrices between requirements, functional and logical architecture (`figures/RLSS html files of traceability matrices/`).
- **Five-block functional architecture** in MATLAB System Composer (`model/RLSS_Functional.slx`, `model/RLSS_Logical.slx`).
- Concept selection by structured brainwriting and a **weighted Pugh matrix**: a shape-memory-alloy-actuated TPU lattice panel that deploys in **18 ms**.
- **Closed-loop physical model** in Simulink (`model/RLSS_Physical.slx`) verified with Simulink Test (`model/RLSS_test.mldatx`) across three passing test cases.
